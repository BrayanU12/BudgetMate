What it does
BudgetMate helps Colombian users (and the broader LATAM market) manage personal finances with features tuned for the local context — including COP currency handling, Nequi/PSE payment culture, and AI-powered financial coaching in Spanish.
Key features

Smart budgeting — expense tracking with category-based insights
AI Financial Coach — personalized financial advice in Spanish via LLM integration
Savings goals — short and long-term goal tracking with progress visualization
Debt calculator — payoff strategies (avalanche vs snowball methods)
Colombia-aware design — COP formatting, local payment methods, regional financial context

Tech stack

Mobile framework: React Native + Expo
Backend: Firebase (Auth, Firestore, Cloud Functions)
AI Layer: LLM integration for the financial coach feature
State management: React Context + hooks
Distribution: Google Play (early access, paid model)

Why the code is private
BudgetMate is a commercial product currently in closed early access on Google Play. The repository stays private during the beta phase to protect the IP and roadmap. This README documents the work without exposing proprietary code.

# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/16UUgw10KhExoD8lullkY8sNlA_Gow4Ho

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
